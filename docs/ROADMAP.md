# Zenora — Build roadmap

## Phase 0 — Foundations (week 1–2)
Monorepo, CI, lint/test, env handling, Postgres + Prisma schema v1, auth (email, Google, OTP stub), workspaces, memberships, RBAC, audit log, app shell matching the design (sidebar, search stub, notifications), feature flags, seed data.

## Phase 1 — MVP: capture and automate (weeks 3–14)
1. Meta app + webhooks ingress; Instagram connect; WhatsApp Embedded Signup; message store.
2. Unified inbox with realtime updates, 24h window, handover, quick replies, templates.
3. Leads: list, profile, timeline, add/import, dedupe/merge, tags, notes.
4. Pipelines: board, stages, custom fields, stage rules, move-stage form, labels/terminology.
5. Automation engine + flow builder (core blocks), trigger setup, test and publish, stats, versioning.
6. Flow templates (starter kits for 4 industries), template editor, save as template.
7. WhatsApp template builder + approval sync; basic broadcasts.
8. Routing, scoring, SLA reassign, salesperson WhatsApp alerts; tasks and sequences.
9. Plans, billing (gateway, GST invoices), limits and usage metering (without AI yet), onboarding flow.
Pilot with 5–10 friendly customers at the end of Phase 1.

## Phase 2 — AI, calls, meetings (weeks 15–26)
AI knowledge base + AI answers, AI scoring and suggested replies; credits, top-ups, alerts, credits-used-up state; telephony integration, dialer, recordings, transcription, summaries; meeting bot; calendar, appointment types, booking page, reminders; reports; ads attribution and audience sync; custom trigger builder; link in bio; mobile web view.

## Phase 3 — Scale and partners
Agency multi-workspace, referral and commission tracking, payouts; owner console (usage, margins, limits editor); API keys and webhooks; privacy tooling (export/delete, retention jobs); security audit (VAPT); performance and load testing; public template gallery.
